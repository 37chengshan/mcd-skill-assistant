# 🍔 麦麦决策实验室 · McDecision Lab

**把“今天吃什么”变成可解释的多目标决策。** 基于麦当劳中国官方 MCP 的独立开源 Skill，集成营养信息、活动日历、个人优惠券读取，并提供预算 × 热量 × 蛋白质的帕累托优化算法。

> 🟡 **参赛作品，非麦当劳官方产品。** 在线静态界面仅展示虚构样例，不会读取你的 Token、不会自动下单。真实数据通过本地 MCP Client 查询；实际餐品、价格、活动和权益均以麦当劳官方实时结果为准。

## ✨ 它能做什么？

| 模式 | 能力 | 数据边界 |
| --- | --- | --- |
| 互动决策面板 | 调预算、热量和蛋白质，实时重新计算方案与可解释理由 | 100% 虚构离线数据 |
| 多目标规划器 | 组合搜索、硬约束过滤、帕累托前沿、确定性排序 | 独立纯函数，可复现 |
| 真实营养分析 | 通过官方 MCP 的 list-nutrition-foods 查询，安全映射字段与单位 | 真实 MCP；字段不明确时拒绝编造 |
| 活动提醒素材 | campaign-calendar 获取实时活动日历 | 真实 MCP，查询不意味着活动一定可用 |
| 我的券包 | query-my-coupons 仅读取本人可用券 | 真实 MCP，绝不自动领券或下单 |

## ✨ V7 候选版：三步生活场景引导

[跟着心情选](docs/journey.html)（本地 `http://127.0.0.1:4173/journey.html`）面向第一次体验作品的人。先选自己吃、朋友吃或一周安排；再调整预算、热量、蛋白质和偏好；最后复用单人、多人、一周功能生成真实运行的演示预览，再将参数带往相应完整页面。

包含上一步/下一步、主动保存本机演示偏好、删除已保存内容及无解提示。保存的只有非敏感设置，不上传身份或账户；数据仍是虚构样例。参见 [引导调度逻辑](docs/journey-engine.mjs) 与 [回归测试](tests/journey.test.mjs)。

## 🎟️ V6 候选版：优惠条件解释与模拟对账

打开 [优惠小算盘](docs/perk.html)（本地预览 `http://127.0.0.1:4173/perk.html`）。这是**完全独立的互动优惠情境工作台**：用户可选不同菜品、工作日/周末，查看每种模拟优惠是否满足条件、还差多少金额、预计可以减少多少，并在小票中对比**一次只能用一种优惠**后的模拟金额。

- 独立的 [docs/perk-engine.mjs](docs/perk-engine.mjs) 处理满减、指定餐品范围、日期限制、折扣封顶；没有价格或异常条件时拒绝计算。
- [tests/perk.test.mjs](tests/perk.test.mjs) 覆盖不叠加、不能享受的原因、最低金额、金额上限与价格缺失。
- 该版本**仅使用虚构优惠和演示价格**；没有读取真实个人券包，也没有做领券、核销、支付、下单或积分操作。网页不会输入账号或密钥。
- 是否真实能用、券是否存在、门店是否参与，只能由具有合法授权的用户通过麦当劳官方渠道核实。当前版本不能宣称真实优惠。

## 🎯 V5 候选版：交互式选择地图

打开 [选择地图](docs/map.html)（本地 `http://127.0.0.1:4173/map.html`），把单调的推荐排序升级为一张可交互的**三指标权衡地图**。横轴显示参考价、纵轴显示热量、圆圈大小代表蛋白质。用户可调整预算、热量上限和蛋白质目标，选择单件餐品或双件搭配，点击图上任意两点或下方文字列表来比较差异。

- 自动区分「各有优势」的方案与「在几个方向上都不更有利」的方案；也能主动选择查看全部候选。
- 点击两份显示花费、热量、蛋白质的有符号差异，避免误称某份对所有人绝对最好。
- 无障碍替代：每个图中圆点有键盘操作和文字标签，下方普通按钮列表可完整选择所有可见方案。
- 独立的 [docs/map-engine.mjs](docs/map-engine.mjs) 与 [tests/map.test.mjs](tests/map.test.mjs) 覆盖所有维度的判定、约束、双件搭配及价格缺失。
- 数据仍是**标明为虚构**的本地演示，图表没有任何在线账户和订餐权限。

## 🗓 V4 候选版：一周午餐灵感日历

打开 [一周食光](docs/week.html)（本地页面 `http://127.0.0.1:4173/week.html`），可以把“只推荐今天这一餐”扩展为 **7 次单独午餐灵感**。独立计算模块会优先选择符合每餐预算、热量和蛋白质目标的餐品，并可调整重复程度；点击任何一天的“换一份”只改变该日，其他六天保持不变。

- 三种场景预设、四个偏好条件、七张日历卡片、每餐指标以及整周参考合计。
- 编辑后的方案可以选择**只保存在当前设备浏览器里**，下次打开重新呈现；可随时删除已存信息。
- 支持下载纯文本餐食清单，不需要账户或联网。
- 离线自动测试覆盖七天限制、变化程度、单日替换、价格缺失和无可选方案；页面采用手机优先布局与自然语言。
- **重要：仅七次虚构午餐，不是七天完整食谱，也不构成医学或营养建议。** 不接入下单或账户信息。

## 👥 V3 候选版：朋友一起选餐

这不是简单添加一个“多人”按钮：新版增加一套独立的多人分配系统。打开 [朋友一起吃](docs/group.html)（本地预览：`http://127.0.0.1:4173/group.html`），可以从两人午餐、三人小聚、四人周末局开始，再自由增减至最多 6 人。每人可编辑自己的参考预算、热量上限、蛋白质目标、选择优先级，以及一项不想吃的食物。

系统会在**个人条件和整桌预算同时满足**的前提下，尝试为每个人分配一份最多两件的搭配，解释整桌参考花费、剩余预算和各人餐食。如果条件互相冲突，会指出哪些人无法满足或最少需要多少预算。分配采用有界候选搜索，不保证数学上的全局最优。**所有食物、价格和营养数字仅为虚构演示**，不是实时门店商品。

- 新模块：[docs/group-engine.mjs](docs/group-engine.mjs)、[docs/group.mjs](docs/group.mjs)、[docs/group.html](docs/group.html)
- 自动化测试：[tests/group.test.mjs](tests/group.test.mjs)
- 无真实订单、支付、优惠券领取及会员数据连接。

## 🍔 V2 候选版：导入电脑里的餐品营养资料

**这是从 V1 的虚构示例到数据驱动体验的产品升级，当前仍需真实授权联调。** 浏览器不连接麦当劳账户，也不接收密钥。使用者在自己的电脑上通过只读服务获取营养资料，导出为严格脱敏的本地文件，再在网页上打开它。原始券包、账户信息和登录凭证绝不会进入网页。

~~~bash
npm install
# 将有效的个人 MCD_MCP_TOKEN 只设置在本机终端
npm run live -- export
npm run preview
~~~

终端生成本机文件 `data/nutrition-snapshot.json`，它已加入 .gitignore，不会通过常规 Git 提交。打开 http://127.0.0.1:4173 ，找到“**打开餐品资料**”，选择这个文件。页面就会用导入的餐品营养数字进行筛选；因为营养服务没有确认的门店价格，**预算筛选会自动暂停**，“更省一点”模式会禁用，结果会显示“价格未知”。上传文件始终在浏览器本地读取，页面不会主动发送它。

**尚未完成的验证**：当前只有格式解析单元测试、静态前端和本地服务检查通过；有效账号的 MCP 实际返回格式、餐品计量单位与数据覆盖度仍要实测确认。网页不会独立确认导入文件是否真实来自官方，最终营养和售价以官方渠道为准。

完整产品级目标见 [MAJOR_RELEASE_ROADMAP.md](MAJOR_RELEASE_ROADMAP.md)；V1 的小改动单独记录于 [ITERATION_REPORT.md](ITERATION_REPORT.md)。

## 🪄 面向普通用户的创新玩法

- **今天想怎么吃？** 均衡一点、更省一点、更有料、轻盈一点，四种心情可以一键切换。
- **各有理由的推荐**：直观看到参考花费、能量和蛋白质，还能了解每一项距离自己定的目标有多少余量。
- **“帮我拍板”**：纠结时随机选一份高亮展示；真实的选择感，而不只是静态卡片。
- **两份摆在一起**：查看预算、能量、蛋白质的差别，不凭空宣称“最省钱”。
- **如果换个想法**：试试另一种目标，看看推荐会如何变化；条件过严时给出可操作的放宽建议。
- **不想吃的排除**：轻点食物标签就能排除；也可以复制安全的分享链接，让朋友沿用同样的偏好。
- **全新手机体验**：暖黄色视觉、紧凑标题、键盘操作支持和适配触控的按钮；页面不向普通用户展示开发者术语。

> **重要**：当前网页完全采用演示数据，真实营养、菜单和价格仍须以麦当劳官方实时信息为准。我们的浏览器页面不会连接你的个人账户，也不接收 Token。

## 🖥 30 秒玩起来

最直观的体验：安装 Node.js 22+ 后用下面的命令启动本地页面。直接双击 HTML 文件可能因浏览器安全限制而不能加载互动功能。

~~~bash
# 电脑已经安装 Node.js 22+ 的情况下
git clone https://github.com/37chengshan/mcd-skill-assistant.git
cd mcd-skill-assistant
npm install
npm run demo
npm test
npm run preview
~~~

然后在浏览器打开 http://127.0.0.1:4173 ，手机和电脑都可使用。页面中的食品和价格属于**明确标注的演示内容**，无需 Token 就能体验创新玩法。

### 一次性开启在线展示

仓库管理者进入 **Settings → Pages → Build and deployment → Source → GitHub Actions** 并保存。之后在 GitHub 的 **Actions → Static preview → Run workflow** 运行一次发布，完成后在线地址通常为 `https://37chengshan.github.io/mcd-skill-assistant/`。在 Actions 显示真正的 `deploy` 成功之前，请勿宣称页面已上线。配置后的后续前端更新会自动发布。

## 🔌 真正连接麦当劳 MCP

1. 按官方指南前往 https://open.mcd.cn/mcp 登录并申请个人 MCP Token。
2. 只在自己的本机终端设置环境变量 MCD_MCP_TOKEN；**切勿提交 .env、真实 mcp-config.json 或 Token**。
3. 在项目目录运行：

~~~bash
npm run live -- tools
npm run live -- nutrition
npm run live -- analyze
npm run live -- calendar
npm run live -- coupons
~~~

终端中 analyze 会对实际返回的营养字段尝试优化；**如果官方数据不含可靠售价，它不会捏造价格或节省金额。** 详见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。云端静态演示永远不使用用户凭证。

## 💡 技术架构

~~~text
                          ┌─ docs/index.html + app.mjs  [完全离线·虚构样例]
用户选择约束 ────────────────┤
                          └─ src/cli.mjs                [本地真实数据模式]
                                 │
                           官方 MCP TypeScript SDK v2
                                 │ HTTPS / Streamable HTTP
                           mcp.mcd.cn (仅只读工具)
                                 │
                    src/normalize.mjs (严格单位 / 缺失检查)
                                 │
                   docs/engine.mjs (统一约束 / Pareto 搜索)
                                 │
                          JSON 输出 + 推荐解释
~~~

优化原则：先筛掉超预算、超热量、蛋白质不足的组合，再保留**不存在其他组合在成本、热量、蛋白质上全面不差且至少一项更好**的非支配方案。最后按透明的启发式得分排序。这是决策辅助，不是绝对最佳饮食建议。

## 🧪 可复现质量与安全

- 纯函数优化，Node.js 自带测试框架；不需要付费 AI API、数据库或个人账号即可测试。
- GitHub Actions 自动检查 Node 语法、单元测试、离线 CLI 示例、参赛必备文件。
- 官方 MCP SDK 负责连接与协议，避免重复实现握手或认证。
- 工具调用采用只读白名单，明确阻止下单、领券、积分兑换及抽奖等副作用操作。
- Web 演示不调用真实 MCP，个人 Token 只从本机环境变量加载。
- 每份营养信息的来源、价格可验证性都明确标注；不会把千焦误当千卡。
